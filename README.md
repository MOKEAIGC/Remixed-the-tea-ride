# The Tea Ride · Remixed

**简体中文** | [English](README.en.md)

《The Tea Ride》是一部 81.6 秒的浏览器短片。骑手坐在一只巨大的鹈鹕背上喝茶，一路穿过集市、追逐柠檬，在落日时从码头起飞，穿过孔明灯群后降落湖面。影片从木版画开场，随着乐句进入立体世界，最后收回画卷并盖上印章。

这个改编版增加了**自由骑行**。你可以操控鹈鹕在街道、空中和湖面探索，单独触发道具和音乐，也可以呼出原片的八段演出。

## 开始游玩

将仓库下载或克隆到本地，用支持 WebGL 2 的浏览器打开根目录的 [index.html](index.html)，选择**自由骑行**或**播放短片**。页面内嵌 Three.js r180，模型、材质、贴图、动画和音频均由代码生成。单个 HTML 文件即可离线运行。

### 自由骑行

| 快捷键 | 操作 |
|---|---|
| `W` / `↑`、`S` / `↓` | 前进、后退。在空中用于提速和减速 |
| `A` / `←`、`D` / `→` | 向左、向右转向 |
| `Shift` | 地面冲刺或空中加速 |
| `空格`、`Z`、`X`、`C` | 起飞、爬升、下降、自动降落到地面或湖面 |
| 拖动、滚轮 | 环绕观察、缩放 |
| `Q`、`E` | 鹈鹕鸣叫、骑手喝茶 |
| `F`、`Shift+F` | 丢一颗柠檬、下柠檬雨 |
| `L`、`Shift+L` | 放一盏孔明灯、放一组孔明灯 |
| `P`、`T`、`V`、`O` | 切换木版画、时段、镜头和全屏 |
| `B`、`Y`、`Shift+1` 至 `Shift+5`、`N`、`M`、`I` | 敲鼓、弹一段筝、弹单弦、展开乐谱、静音、暂停 |
| `H`、`Esc`、`R` | 打开控制台、收起面板或退出当前演出、返回起点 |

也可以点击右上角的**控制台**使用面板按钮，触屏上还有方向和飞行控件。按住 `W`、`Shift` 和 `Z` 可在空中加速爬升。用 `T` 切到月夜，再按 `Shift+L` 可放飞一组孔明灯。点击场景物件也能触发相应的声音或动作。

穿过集市入口、茶摊和码头的三个金色标记即可打卡。在本地页面地址末尾加 `?ride` 可直接进入自由骑行。

### 动作组合与位点演出

| 快捷键 | 内容 |
|---|---|
| `U` | 到茶摊弹筝、喝茶、鸣叫 |
| `G` | 到码头切换落日，鸣叫后助跑起飞 |
| `J` | 在月夜起飞，分三批放飞孔明灯 |
| `K` | 降落后喝茶，再放一盏孔明灯 |
| `1` 至 `8` | 分别播放原片的日出开场、集市、茶歇、柠檬追逐、码头起飞、穿越灯海、月下落湖和收画落印 |

原片桥段播完后会回到演出前的位置。按 `Esc` 或演出横幅上的返回按钮可提前退出。按转向键或 `Esc` 可中断正在进行的动作组合。

### 短片模式

| 输入 | 操作 |
|---|---|
| 点击场景中的物件 | 物件在下一个十六分音符处按当前调性响应 |
| 点击空处 | 抛出一颗带物理模拟的柠檬 |
| 拖动、滚轮 | 环绕观察、缩放 |
| `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` | 弹筝 |
| `B`、`Q`、`W`、`E` | 敲鼓、鸣叫、喝茶、下柠檬雨 |
| `R` | 切换随骑视角 |
| `P` | 将当前画面切换为木版画 |
| `N` | 展开乐谱 |
| `空格`、方向键、`M`、`X` | 暂停、跳转、静音、全屏 |

## 乐谱如何驱动画面

合成器和场景动画共用 [src/06_score.js](src/06_score.js) 中的音符表。短片速度为每分钟 100 拍，共 34 小节。

| 声部 | 画面响应 |
|---|---|
| 筝 | 集市中每组有八盏灯，分别响应不同音高。飞行段由孔明灯接续 |
| 笛 | 茶杯上方的蒸汽随旋律升降，蒸汽带的宽度随气息变化 |
| 马林巴，第 12 至 17 小节 | 柠檬在对应音符处碰撞杯碟，碰撞之间遵循重力 |
| 低音 | 遮阳棚、树木、尾羽、骑灯和鹈鹕周围的水波 |
| 太鼓 | 石板和镜头晃动 |
| 打击木块 | 百叶窗、阳伞和拍手 |
| 铃声 | 水波和星光 |
| 和弦 | 热气球的燃烧器 |
| 脚步和振翅 | 随节拍动作，脚掌落下时压动石板 |

## 源码结构

`src/` 下的脚本按文件名顺序拼接。构建脚本将 Three.js 和项目源码内嵌到 `dist/pelican-market-3d.html`，仓库根目录的 [index.html](index.html) 是该成品的副本。

| 文件 | 用途 |
|---|---|
| `00_util.js`、`02_sdf.js`、`04_sculpt.js` | 几何处理、有符号距离场、网格生成和骨骼蒙皮 |
| `06_score.js` | 音符、剧情时间点和动画查询 |
| `08_look.js`、`10_sky.js` | 材质、风、阴影、木版画材质效果和昼夜光照 |
| `16_path.js` | 鹈鹕在原片中的路线和运动状态 |
| `30_phys.js`、`56_lemons.js` | 柠檬物理、杯碟碰撞和追逐段落 |
| `40_pelican.js`、`41_lamp.js`、`42_rider.js`、`43_steam.js` | 鹈鹕、骑手、骑灯和茶杯蒸汽 |
| `44_beasts.js`、`46_folk.js` | 六种动物和 159 位镇民 |
| `50_arch.js`、`54_stalls.js` | 街道、房屋、码头、摊位、布料和灯笼 |
| `60_land.js`、`64_water.js`、`66_air.js` | 山地、植物、湖面、水花、气球、云、孔明灯和鸟群 |
| `80_post.js` | 环境光遮蔽、光束、景深、辉光、调色和木版画后期 |
| `85_audio.js` | 在 Worker 中逐采样合成乐器和音效 |
| `86_ride.js`、`86_ride_trail.js` | 自由骑行、飞行、碰撞和三个打卡点 |
| `87_ride_show.js`、`87_ride_ui.js` | 动作组合、位点演出和交互面板 |
| `87_scorestrip.js`、`88_film.js`、`89_player.js`、`90_main.js` | 乐谱界面、原片镜头、输入及播放、渲染循环 |

播放器会在连续多帧耗时过长时降低内部渲染分辨率。

## 构建、调试和导出

```bash
python3 -X utf8 tools/build.py
```

构建时会用 Node.js 检查脚本语法。构建后可以直接打开 `dist/pelican-market-3d.html`。要更新仓库根目录的可玩版，将构建产物复制为 `index.html`。

`tools/` 还包含无界面 Chrome 截帧工具（`capd.mjs`、`cap.py`）、性能和三角形统计（`perf.py`、`tris.py`）、音轨和响度分析（`stems.mjs`、`listen.py`），以及逐帧渲染和视频导出（`render.mjs`、`finish.py`）。按工具所需准备 Node.js、Python 3、Pillow、NumPy 和本机 Chrome。截帧与渲染脚本默认使用 macOS 的 Chrome 路径和 Metal 设置。导出 MP4 还需 FFmpeg。
